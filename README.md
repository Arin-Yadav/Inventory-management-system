# Inventory Management System

A full‑stack application built with the **MERN stack** (MongoDB, Express, React, Node.js) and styled using **Tailwind CSS**. The project provides a clean, responsive dashboard for managing products, suppliers, categories, and stock movements. State management is handled with React’s **Context API**.

---

## Features

- **Authentication & Authorization**
  - Secure login and registration with JWT
  - Role‑based access control for admin and staff

- **Products**
  - Create, update, and delete products
  - Assign categories and suppliers
  - Track stock levels and reorder thresholds

- **Suppliers**
  - Manage supplier details
  - Link suppliers to products

- **Categories**
  - Organize products into categories
  - Simple CRUD interface

- **Stock Movements**
  - Record IN, OUT, and ADJUSTMENT transactions
  - History log with timestamps and user details

- **Dashboard**
  - Alerts for low stock items

---

## Tech Stack

- **Frontend**
  - React.js
  - Tailwind CSS
  - Context API for global state

- **Backend**
  - Node.js + Express
  - MongoDB with Mongoose
